# Временная страница ВСЗ

Уведомление о временной недоступности основного сайта Вятского станкостроительного завода. Посетитель может позвонить в отдел продаж, нажав номер или красную кнопку. Страница работает на HTML и CSS, использует локальные изображения и локальный Open Sans.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Текст уведомления, шапка, телефон, кнопка звонка и метатеги |
| `styles.css` | Палитра, типографика, расположение блоков и мобильная версия |
| `assets/vsz-logo.webp` | Логотип из «Логотип кругляш-1.png» для шапки и подвала, WebP с прозрачностью |
| `assets/favicon.png` | Значок вкладки браузера |
| `assets/production-{480,768,1200,1600,2048}.webp` | Полный производственный кадр для телефонов и планшетов, ширина в пикселях указана в имени |
| `assets/production-detail-{720,1120,1700}.webp` | Кадр 5:4 для правой половины широкого экрана, с сотрудником и рабочей зоной станка |
| `assets/fonts/open-sans-{regular,semibold,bold}.woff2` | Локальные Open Sans 400, 600 и 700 |
| `assets/fonts/LICENSE.txt` | Полный текст лицензии Apache 2.0 для шрифтов |
| `.nojekyll` | Публикация готовых статических файлов без обработки Jekyll |

## Шрифты

WOFF2 подготовлены из предоставленных TTF Open Sans 1.10 производства Ascender Corporation. При конвертации сохранены все исходные символы кириллицы, базовая латиница, цифры, знаки препинания, хинтинг и исходные метаданные. Обычный текст и подвал используют Regular (400), название в шапке и телефон — SemiBold (600), заголовок и кнопка — Bold (700).

## Фотография первого экрана

Оба набора WebP получены из `PROZ4176.jpg` (2048 × 1365). На узких экранах оригинальная композиция занимает всю ширину после кнопки. Начиная с 68 em (1088 px при базовом шрифте 16 px) элемент `picture` выбирает кадр 5:4 для правой половины экрана. На узком экране `sizes` равен `100vw`. Для правой колонки он учитывает и её ширину (`50vw`), и размер кадра 5:4, нужный для заполнения колонки по высоте с `object-fit: cover`. Так высокий экран получает достаточно детальный снимок. Браузер выбирает один файл с учётом плотности пикселей. Место под фото резервирует CSS, приоритет загрузки задан на `img`.

При замене фото обновите соответствующие WebP, размеры, пути и описание фотографии в `index.html`. На 320, 768 и 1440 px проверьте кадр, видимость контактов, выбранный `currentSrc` и число запросов к фото. Измерения итерации привязаны к проверенному коммиту в описании PR.

## Локальный просмотр и редактирование

Для проверки локальных шрифтов запустите `python -m http.server 8000 --bind 127.0.0.1` из корня репозитория и откройте `http://127.0.0.1:8000/`. Сборка и установка пакетов не требуются.

Вносите изменения в отдельной ветке. Текст и контактные данные редактируются в `index.html`. При смене телефона обновите видимый номер, описание страницы и оба адреса `tel:`. На узком экране проверьте переносы текста и видимость кнопки. Пройдите обе ссылки клавишей Tab и проверьте, что они указывают на один номер. Затем откройте Pull Request в `main`.

## Публикация на GitHub Pages

После согласования и объединения PR откройте **Settings → Pages → Build and deployment**. При первой публикации выберите **Deploy from a branch → main → /(root)** и нажмите **Save**. Последующие изменения публикуются при обновлении `main`. Ход публикации виден во вкладке **Actions**.

Целевой адрес — [страница ВСЗ на GitHub Pages](https://volkov43-beep.github.io/vsp-kirov-maintenance/). Сохраняйте пути к ресурсам относительными, чтобы они работали в подпапке проекта. Для этой публикации собственный домен не требуется.
